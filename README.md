# Autoneum Challenge 2026

Arbeitsunterlagen zur Autoneum Challenge – TAF-Blockwoche, 7.–11. September 2026.

**Gewählte Challenge:** Robotaxi / Cabin Comfort, mit Fokus auf den **reinigbaren
Innenraumboden** für privat gehaltene autonome Fahrzeuge, die zeitweise als Robotaxi
vermietet werden.
